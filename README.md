# 📊 Executive KPI Dashboard

## Problem
Executives had no real-time visibility into business performance. Support tickets for data requests were high.

## What I Did
- Built 8 Power BI dashboards with defined SLAs
- Trained 12 team members on SQL and Power BI
- Implemented row-level security (RLS)

## Tech Stack
- Power BI (DAX)
- SQL Server
- Row-Level Security (RLS)

## Results
| Metric | Result |
|--------|--------|
| Query response time | Under 10 seconds |
| Support tickets | 30% reduction |
| Team promotions | 2 to senior roles |
